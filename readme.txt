Simplified WooCommerce product inventory dashboard for StoryPhone shop admins.

== Description ==

StoryPhone Inventory Manager provides a mobile-first merchant inventory screen
inside wp-admin. All product reads and writes go through the WooCommerce CRUD API.

== Installation ==

1. Build the React app: `npm install && npm run build` inside this plugin folder.
2. Upload the `storyphone-inventory-manager` folder to `/wp-content/plugins/`.
3. Activate WooCommerce first, then activate this plugin.
4. Open **StoryPhone Inventory** in the WordPress admin menu.
